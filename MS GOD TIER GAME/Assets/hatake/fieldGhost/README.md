# お化けのフィールド演出（fieldGhost）

戦闘以外でもお化けを見せるための演出です。どれも当たり判定はなく、見せるだけです。

| 演出 | コンポーネント | 中身 |
|---|---|---|
| カーテン越しの形 | `FieldGhostCurtain` + `FieldGhostCurtainPress` | 白の半透明カーテン。窓との間を何かが横切り、止まって顔と両手を押し付け、離すと揺れる |
| 床の冷気にとける | `FieldGhostFloorMelt` | 床の霧が濃くなった所から伸び上がって現れ、道筋を進み（跡の霧が割れる）、床へつぶれながら霧に溶ける |
| 壁をすり抜ける | `FieldGhostWallPeek` | 壁から上半身だけ出てこちらを見て、ねじれながら引っ込む。または部屋を横切って向かいの壁へ入る。壁の面で切り、切り口が光る |

## 置き方

ヒエラルキーで右クリック → **お化けの演出** から置けます。

- **白のカーテン**: そのまま作られます。オブジェクトの位置が**カーテンレールの中央**、青の矢印（+Z）が**部屋側**、裏が窓側です。窓の手前に置いてください。
- **床の冷気にとける**: シーンに置いたお化け（ゴースト用マテリアルのもの）を選んでから実行します。子の「現れる所」「溶ける所」を動かして道筋を決めます（点は増やせます）。
- **壁をすり抜ける**: お化けを選んでから実行します。できたオブジェクトを**壁の表面**へ動かし、青の矢印を部屋側へ向けます。「部屋を通り抜ける」にするときは、向かいの壁の表面に空のオブジェクトを置いて `exitWall` に入れます（そちらも +Z を部屋側へ）。

お化けは、プレイを始めると隠れ、演出のときだけ出ます。

## 出る条件（3 つ共通）

- 既定は「近づいたら」（Main Camera が `triggerRadius` の内側に入った瞬間）。
- `requireInView` が ON なら、演出の場所が画面に映るまで待ちます。
- `chance`（確率）・`playOnce`（1 回だけ）・`cooldown`（次までの秒数）で出し過ぎを防ぎます。
- 「スクリプトから Play() を呼ぶ」にすると、ゲーム側から `Play()` / `Stop()` で動かせます。

## 色と見た目の調整

- **カーテンの色**: `materials/M_FieldGhostCurtain` の「布の色」。α が濃さです。裏から透ける光の色・強さ、押された所の影の色・発光もここで変えます。複数の色を使うときはマテリアルを複製してください。
- **カーテンの形と風**: `FieldGhostCurtain` で変えます。
  - ひだ: `pleatCount`（細かいひだの数）・`pleatDepth`（深さ）・`pleatIrregularity`（不揃いさ）・`largeFoldCount`（裾の大きな折れ目の数）
  - 風: `windStrength`（ふだんのふくらみ）・`gustStrength`（突風のふくらみ）・`gustFrequency` と `gustiness`（突風の頻度と長さ）・`lateralFlap`（裾が横へめくれる量。負で左）・`flutter`（細かい波）・`twist`（斜めのねじれ）
  - 無風にしたいときは `windStrength`・`gustStrength`・`flutter` を 0 にします。カーテンを複数置くときは `seed` を変えると動きがそろいません。
- **ひだの陰**: マテリアルの「ひだの谷の陰」。
- **光をさえぎる（影）**: カーテンは揺れ・ひだ・折り曲げをそのまま反映した影を落とし、窓からの光（床の光の溜まり）や光の筋（LightShaft の霧の中の筋）をさえぎります。
  - 濃さはマテリアルの「光をさえぎる強さ」（0 で素通し、1 で完全に遮る）。布なので既定は 0.7。網目状に影を落としてソフトシャドウでならすので、ライトの影を Soft にすると自然に見えます。
  - 影を落とさないようにするには、`FieldGhostCurtain` の `castShadows` を OFF。
  - さえぎれるのは影を使う光だけです。光源（ライト）側で影（Shadow Type）が有効になっている必要があります。
- **God Ray を遮る**: 画面の空から放射状に出る God Ray（LightShaft の Sky Occlusion）も、カーテンの形どおりに「光をさえぎる強さ」の分だけ遮ります。`FieldGhostCurtain` の `blockGodRays` で切り替え（既定 ON）。
  - 仕組み: LightShaftFeature が、シェーダに `LightMode = "GodRayOccluder"` のパスを持つレンダラーを集めて低解像度に描き、空の判定から差し引きます。ほかの半透明（すりガラスなど）も、このパスを足せば遮るものとして数えられます（出力の R が遮る強さ 0〜1。重なりは濃い方）。

## カーテンを折り曲げる・箱に貼り付ける

- **折り目（支点）**: `FieldGhostCurtain` の「折り曲げ（支点）」に最大 4 本まで足せます。シーンでは黄色の線で見えます。
  - 縦の折り目: `position` は中央から右へ m（負で左）。そこから外側（左右）の布を `angle` 度だけ曲げます。正で奥（窓・箱の側）、負で手前。
  - 横の折り目: `position` はレールから下へ負の m。そこから下の布を曲げます（縁から垂らす、ひさしのように張り出すなど）。
  - `radius` は角の丸み。ひだの深さより少し大きくすると布が食い込みません。
- **箱に貼り付ける**: 「貼り付ける箱（wrapTarget）」に箱を入れ、面の数（前だけ／前と左右の 3 面／ぐるり 4 面）と正面の向きを選んで、インスペクタ下の「**箱に貼り付ける**」ボタンを押します。位置・向き・幅・高さ・折り目が自動で決まります（元に戻すは Ctrl+Z）。
  - 箱の大きさは BoxCollider があればそれ、無ければメッシュから取ります。
  - `wrapGap` で箱から浮かせる距離、`wrapCornerRadius` で角の丸みを変えます。
  - 巻き付けたあとも、ひだ・風・お化けの押し付けは布の面に沿って効きます。風を止めたいときは `windStrength`・`gustStrength`・`flutter` を 0 に。
- **お化け**: いまのゴースト用マテリアル（`custom/hatake/ToonMaster`、表面の種類＝ゴースト）をそのまま使います。伸び縮みには `TeamToonGhostDeformer` と、各マテリアルの「変形（デフォーマ）を使用」が必要です。
- **壁の切り口の色**: `FieldGhostWallPeek` の「切り口」。
- **霧**: `FieldGhostFloorMelt` の「霧」。シーンの霧（LightShaft の Fog）の濃さに合わせて `puffDensity`・`trailStrength` を調整してください。霧の塊は `LocalFogVolume` を演出中だけ置きます（同時に描けるのは全体で 16 個まで。跡は 6 個までを使い回し、足りないときは跡から先に落ちます）。

- `chara/shader/TeamToon*`: 切り口（`_SliceEnabled` / `_SlicePlane` / `_SliceGlowColor` / `_SliceGlowWidth`）を追加。既定は切らないので、今のお化けの見た目は変わりません。
- `chara/script/TeamToonGhostDeformer.cs`: スクリプトから伸び縮みを決める `SetStretchOverride` / `ClearStretchOverride` を追加。呼ばなければ今までどおりです。
